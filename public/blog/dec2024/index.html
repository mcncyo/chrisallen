Life Updates: Servers, Computers, and Personal Changes

A detailed update on my recent server changes, computer upgrades, website hosting decisions, and personal life events.
December 24, 2024 · Chris Allen

Sorry for the lack of updates lately! The past few months have been incredibly hectic with everything going on in my life, server setup, and main computer. Here’s a quick rundown of what’s been happening:

Server Updates#

I recently transitioned from Proxmox to a TrueNAS server, which has been quite the journey. On my TrueNAS setup, I’ve created a Docker VM using Jailmaker. This VM hosts several critical services:

  • My homepage
  • Nginx Proxy Manager
  • Mealie: A digital cookbook platform
  • Mosquitto: An MQTT broker
  • Paperless: For managing my PDF files
  • Vaultwarden: A self-hosted password manager I’m setting up to replace Bitwarden servers

Additionally, I’m using the Apps feature on TrueNAS to run an Omada server VM for managing my TP-Link wireless access points. I also utilize its virtualization capabilities to host my Home Assistant server.

Main Computer Updates#

My main computer is a Dell machine that was previously running Windows 10. I’ve since switched it to Pop!_OS, which is based on Ubuntu. Here’s what I’ve set up so far:

  • Installed Firefox, VS Code, and DaVinci Resolve
  • Set up Docker, Zsh, Hugo, and several other tools
  • Began learning and configuring Neovim for more efficient development

Switching to Pop!_OS has been a refreshing change, and I’m excited to continue exploring its capabilities.

Website Hosting Changes#

Just yesterday, I created a Droplet on DigitalOcean to host this site and ComputerHacking101.com. Previously, I hosted these sites on my home server, but there were issues with downtime whenever I needed to take the server offline or experienced internet outages. By moving to DigitalOcean, I’m aiming for 99% uptime, ensuring the sites are almost always available for you.

Personal Updates#

On a more personal note, it’s been a tough time for my family. My grandmother is still alive but is unwell and coughing a lot. Sadly, my wife lost two of her uncles around Thanksgiving, which coincided with both of us being sick as well. It was a rough couple of weeks for our family.

Thanks for sticking with me through all of this. I’ll keep you posted with more updates soon!
